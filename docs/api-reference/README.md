## How to use this set

1. Start with the module that owns the feature you want to change.
2. Cross-check the controller path in the source tree.
3. Follow the service entry points and DTOs to understand the implementation path.

> These guides are intentionally implementation-oriented. They are meant to complement the existing architecture notes rather than replace them.
