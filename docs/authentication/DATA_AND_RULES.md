# Authentication and Authorization Data and Rules

Role-permission entities are in `Codeji.CMS.Repository/Entities/RolePermissions`. Permission constants/constraints and `ModulePermission` usage define module action grants. The authenticated company context is a security boundary that domain services must apply to reads and writes. Supporting references: `../auth-and-permissions.md`, `../authentication-and-authorization-reference.md`, and `../roles-and-permissions-complete-reference.md`.
