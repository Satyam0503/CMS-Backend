# UNVERIFIED, PARTIAL & UI-ONLY AREAS REGISTER (`UNVERIFIED-AREAS.md`)

> **Rule Compliance Statement**: Per Section 1 of the Codex Master Task (*"Never invent an endpoint, entity, field, rule, dependency, relationship, permission, workflow, or feature. ## 2. Verification Methodology Used
Every finding above was established by:
1. Scanning all `.cs` controllers, services, repositories, entities, and hosted services inside `CMS-Backend-Core/`.
2. Scanning all `.tsx` / `.ts` pages, components, Redux slices, TanStack Query hooks, and Axios interceptors inside `CMS-React/src/`.
3. Tracing every HTTP endpoint from frontend service call to backend controller action and MongoDB collection operation.
4. Explicitly separating **verified production code** from **roadmap / external integration boundaries**.
