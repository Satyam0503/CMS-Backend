# Recruitment and Career Portal

Internal recruitment controllers are `ApplicantsController` and `JobVacancyController`. Public career APIs are `PublicCareerController`, `PublicCareerEngagementController`, `PublicCareerSubscriptionController`, `PublicCompanyProfileController`, and `CareerProfileController`. Sources and current flow are documented in `../recruitment-current-flow-and-working-context.md` and `../career-page-current-flow.md`.

Public endpoints must be assessed separately from authenticated staff APIs; public does not imply unrestricted cross-company data.
